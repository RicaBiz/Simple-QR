# Simple-QR
ultra simple Alphanumeric QR Code generator from string to QR.

## How to use:
Download the html and js from the release. Open the html in your browser.
Insert the alphanumeric string into the text input, click Crea QR.
Done.

## Options
You can adjust the scale in the numeric input. Default value is 6, up to 20, but you can change the html as you please.

## Save
If you want to download the QR just right click it and save image.
